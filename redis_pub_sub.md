# **Redis Pub Sub**
Pub or Publisher and Sub or Subscriber is a real time messaging model where the publisher sends messages to the subscribers.
The subscribers receive the messages from the publisher.

---------------

## **Working of Redis Pub Sub**
1. We have to import redis.
2. We have to create a redis connection.
3. We have to create a publisher.
4. We have to create a subscriber.
5. We have to subscribe to the channel.
6. We have to publish a message to the channel.
7. We have to receive the message from the channel.
8. We have to close the connection.


---------------


## **Real life example of Redis Pub Sub**
Imagine there is a FM radio station.
Now, Radio station 's RJ is the publisher and the channel or the topic is radio statio's channel like 98.3 FM.

## **How Pub Sub Works?**
1. The publisher sends a message to the channel.
2. The subscribers receive the message from the channel.
3. The subscribers can process the message.
4. The subscribers can print the message.
5. The subscribers can close the connection.
6. The publisher can close the connection.
